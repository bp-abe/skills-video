# Vozes clonadas (fora do git)

Guarde aqui a referência de cada voz autorizada, uma pasta por pessoa:

| Arquivo | O que é |
|---|---|
| `<nome>/ref.wav` | 12–17 s de fala natural, 24 kHz mono, sem música nem eco |
| `<nome>/texto.txt` | a transcrição exata desse áudio (melhora muito a clonagem) |

**Clonagem de voz só com autorização por escrito de quem fala.** Esta pasta está no `.gitignore`: vozes nunca vão para
o repositório. Aponte `voz_params.referencia` e `referencia_texto` no `template/roteiro.json` para a sua pasta.
